# Speak Daily

App web de estudo de inglês: lições (dias, meses, anos, números, horas, cores, família, verbos, dia a dia), conversas e tarefas diárias. Funciona offline como PWA.

## Publicar no GitHub Pages
1. Envie todo o conteúdo desta pasta para um repositório (arquivo `index.html` na raiz).
2. Em Settings → Pages, escolha a branch `main` e a pasta `/ (root)`.
3. Abra o endereço gerado no celular e use "Adicionar à tela inicial".

Para atualizar o app depois, mude `V` em `sw.js` (ex.: `speakdaily-v2`).
